# Real-data validation — RTX 2070 (2026-06-28)

Full real stack on real video, end to end: **YOLO26n-pose → ByteTrack → SAM 2.1 (box-prompted) →
temporal transformer trained on the UR Fall Detection Dataset**. No synthetic fallbacks, no fabricated
numbers. Host: NVIDIA RTX 2070 8 GiB, driver 595.71.05, PyTorch 2.12.1+cu130, FP16, 640 px input.

## Action model (real data)

Trained on UR Fall Detection (URFD) cam0 RGB. YOLO26-pose extracts COCO-17 skeletons; 32-frame windows
labelled from the URFD per-frame annotation (`upright` / `falling` / `fallen`). **Split by sequence**
(held-out fall sequences `fall-04,06,13,25,28,29`) so no window leaks between train and validation.

- Train windows: 927 (`upright` 662, `falling` 136, `fallen` 129) — inverse-frequency class weights.
- Validation windows: 60 on held-out sequences.
- **Best validation macro-F1: 0.90** (accuracy 0.93).
- Confusion matrix (rows = true `[upright, falling, fallen]`):

  ```
  [[12  0  0]
   [ 3 26  0]
   [ 0  3 16]]
  ```

## Reproduce

```bash
make install-ml && make models
make dataset-real     # downloads URFD, extracts poses, trains on the sequence split
make benchmark-real   # this table
make demo-real        # live dashboard at http://localhost:8080
```

Dataset: UR Fall Detection Dataset, M. Kepski & B. Kwolek, University of Rzeszów
(http://fenix.ur.edu.pl/~mkepski/ds/uf.html). Downloaded locally; not redistributed by this repo.
