## Optimization finding

The first end-to-end run invoked SAM on every frame because low-confidence keypoints bypassed the normal interval. It produced 24.5 FPS and 28.4% stage drops. Adding `uncertain_every_n_frames` and enforcing a cooldown produced the zero-drop result above. This is why latency distributions, stage queues and drop counters are part of the acceptance gate.

Raw JSON and Markdown artifacts are generated under `artifacts/benchmarks/` and are intentionally not committed. Reproduce with:

```bash
python scripts/benchmark_pipeline.py \
  --config config/benchmark-gpu.yaml \
  --warmup-seconds 3 --seconds 10
```
